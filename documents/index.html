Complete VPS Installation Guide

Follow these 8 steps to deploy your FixBro Interiors website on a fresh Ubuntu/Debian VPS with MySQL, auto-generated admin credentials, PM2 process management, Nginx reverse proxy, and free HTTPS SSL.

Recommended OSUbuntu 22.04 / 24.04
RuntimeNode.js 20 LTS+
DatabaseMySQL 8.0+
App Port3004 (Proxied via 443)
1

Prepare VPS & Install Node.js 20+

Connect via SSH and install Node.js, Git, and PM2.

Log in to your VPS using SSH (ssh root@YOUR_SERVER_IP) and update system packages:

bash — Update & Install Node.js 20
sudo apt update && sudo apt upgrade -y
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git build-essential
node -v && npm -v

Install PM2 globally so your website stays online 24/7 and restarts automatically after crashes or reboots:

bash — Install PM2
sudo npm install -g pm2
2

Install & Configure MySQL

Create a dedicated database and user for the application.

bash — Install MySQL Server
sudo apt install -y mysql-server
sudo systemctl enable --now mysql
sudo mysql

Inside the mysql> prompt, create the database and user (replace YOUR_STRONG_DB_PASSWORD):

sql — Create Database & User
CREATE DATABASE IF NOT EXISTS fixbro_interiors CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'fixbro_user'@'localhost' IDENTIFIED BY 'YOUR_STRONG_DB_PASSWORD';
GRANT ALL PRIVILEGES ON fixbro_interiors.* TO 'fixbro_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
High Traffic Tip (1 Lakh+ Visitors) MySQL defaults to ~151 max_connections. Our pool uses MYSQL_CONNECTION_LIMIT=15 per Node instance, so it comfortably supports scaling up without exhausting connections.
3

Upload Project & Install Dependencies

Place your code in /var/www/fixbro and run npm install.

Create the project directory, upload your files (via SFTP, FileZilla, or git clone), and install packages:

bash — Setup Directory & Dependencies
sudo mkdir -p /var/www/fixbro
sudo chown -R $USER:$USER /var/www/fixbro
cd /var/www/fixbro
# Upload or clone your project files here
npm install
4

Configure Environment (.env)

Copy documents/example.env to .env and set your domain & DB credentials.

bash — Create .env from Template
cp documents/example.env .env
nano .env

Template contents (also saved in documents/example.env):

.env — Reference Configuration
# Application Configuration
NEXT_PUBLIC_APP_NAME="FixBro Interiors"
NEXT_PUBLIC_WEBSITE_URL="https://yourdomain.com"
NEXT_PUBLIC_BASE_URL="https://yourdomain.com"
PORT=3004

# MySQL Database Configuration
MYSQL_HOST="127.0.0.1"
MYSQL_PORT=3306
MYSQL_DATABASE="fixbro_interiors"
MYSQL_USER="fixbro_user"
MYSQL_PASSWORD="YOUR_STRONG_DB_PASSWORD"
MYSQL_CONNECTION_LIMIT=15

# Authentication & Initial Admin Setup
# Leave blank to auto-generate secure values on first `npm run init-db`.
# Existing values are always preserved.
AUTH_SECRET=
ADMIN_USERNAME=
DEFAULT_ADMIN_PASSWORD=
How Auto-Generation Works If AUTH_SECRET, ADMIN_USERNAME, or DEFAULT_ADMIN_PASSWORD are left blank or omitted, npm run init-db automatically generates secure random values and saves them into .env. If they already exist, it keeps your existing values untouched.
5

Initialize Database & Build App

Create tables, indexes, default content, admin user, and compile production bundle.

bash — Initialize DB & Build
npm run init-db
npm run build

Check your generated admin credentials in .env so you can log in after deployment:

bash — View Generated Admin Credentials
grep -E "ADMIN_USERNAME|DEFAULT_ADMIN_PASSWORD" .env
6

Start & Persist App with PM2

Run the Next.js production server on port 3004.

bash — Start with PM2
pm2 start npm --name "fixbro" -- start
pm2 save
pm2 startup

Copy and run the sudo env PATH=... command that pm2 startup prints so PM2 auto-starts on server reboot. Then verify:

bash — Verify Local Server
pm2 status
curl -I http://127.0.0.1:3004
7

Configure Nginx Reverse Proxy & Free SSL

Point your domain to port 3004 and enable HTTPS with Certbot.

bash — Install Nginx & Certbot
sudo apt install -y nginx certbot python3-certbot-nginx
sudo nano /etc/nginx/sites-available/fixbro

Paste this Nginx config (replace yourdomain.com with your domain):

nginx — /etc/nginx/sites-available/fixbro
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;

    client_max_body_size 100M;

    location / {
        proxy_pass http://127.0.0.1:3004;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

Enable the site, test Nginx, and issue your free Let's Encrypt SSL certificate:

bash — Enable Site & Issue SSL
sudo ln -s /etc/nginx/sites-available/fixbro /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
8

Post-Install Admin Panel Setup

Secure your admin account and configure Razorpay, Email & SEO.

  1. Open https://yourdomain.com/admin/login in your browser.
  2. Sign in with ADMIN_USERNAME and DEFAULT_ADMIN_PASSWORD from .env.
  3. Go to Profile (/admin/profile) and immediately change your admin email and password.
  4. Open Settings (/admin/settings) to configure:
    • General Settings: Brand name, logo, favicon, social links.
    • Email (SMTP): Host, port, username, password, sender email.
    • Payment Gateway (Razorpay): Key ID, Key Secret, Webhook Secret.
  5. In your Razorpay Dashboard, set the Webhook URL to:
    Webhook URL (subscribe to payment.captured & order.paid)
    https://yourdomain.com/api/razorpay/webhook
You're Live! Your FixBro Interiors site is now running with HTTPS, MySQL connection pooling, static/ISR route caching, and protected admin endpoints.
